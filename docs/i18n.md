# 界面语言（中英双语）

> 第六波（docs/wave6-plan.md §5、D18–D23）。本文是开发约定：怎么选语言、文案放哪、键怎么起名、怎么测。
> 调研依据见 [research/wave6/R8-i18n.md](research/wave6/R8-i18n.md)。

## 语言怎么定

优先级从高到低，**进程启动时定一次**，不做运行中切换：

1. 环境变量 `AMA_LANG`（`zh` / `en`，`zh_CN` 之类也认；写错的值忽略）；
2. 命令行 `--lang zh|en`（也可写在子命令前：`ama --lang en doctor`）；SDK `createRuntime({ language })` / `createAgentSession({ language })` 等价；
3. profile 的 `language`（嵌入宿主跟随画布界面语言）；
4. 配置 `ui.language`（`auto` / `zh` / `en`，缺省 `auto`；用户级 / 项目级都可设）；
5. `LC_ALL` → `LC_MESSAGES` → `LANG` 第一个非空值：`zh*` 为中文，其余（含 `C`、`POSIX`、`en_*`）为英文；
6. 都没有：英文。

`cli/main.ts` 在解析参数后、任何输出前按 1、2、用户级 `ui.language`、5 定语言；bootstrap 合并 profile 与项目级后，若它们给了 `ui.language` / `language`，再补定一次（仍以 1、2 为准）。`ama doctor` 显示「界面语言：zh（来源 LANG=zh_CN.UTF-8）」（`resolveLocaleWithSource`）。

**界面语言只影响给人看的文字。** 发给模型的一切（系统提示、工具描述、工具结果里的标记、截断 / 裁剪占位、外部 Agent 报告、Hook 阻止理由、拒绝理由）固定英文，两种语言下请求逐字节相同。想让模型用某种语言回复，用 `ui.replyLanguage`（在 `rules` 节末尾追加一句英文规则，不设时零字节变化）。

## 文案放哪

```text
src/i18n/
  index.ts      Locale、resolveLocale / resolveLocaleWithSource、setLocale / getLocale、msg()、messagesFor()
  types.ts      Messages<T>
  format.ts     plural()、formatDuration()
  catalog.ts    汇总全部领域（第六波 C0 一次登记，之后无人再改）
  messages/<领域>.ts
```

| 领域文件                                                             | 归属批次                              |
| -------------------------------------------------------------------- | ------------------------------------- |
| `cli`、`subcommands`                                                 | W6-I1                                 |
| `interactive`、`approval`、`plan`、`rewind`、`panels`、`permissions` | W6-I2                                 |
| `report`、`print`、`drivers`、`session`、`errors`                    | W6-I3                                 |
| `config`                                                             | W6-I4                                 |
| `agents` / `trace` / `memory` / `auth` / `settings`                  | W6-A / W6-T1、T2 / W6-M / W6-O / W6-S |

每个领域文件同时导出 `en`（形状源）与 `zh`：

```ts
import { plural } from "../format.js";
import type { Messages } from "../types.js";

export const en = {
  limitTurns: (limit: number) => `ama: reached the turn limit ${limit}; run ended early`,
  dirSummary: (files: number, size: string) => `directory, ${plural(files, "file")}, ${size}`,
  approval: { title: "Approve tool call", keys: { allow: "allow", deny: "deny" } },
};

export const zh = {
  limitTurns: (limit) => `ama: 已达到回合上限 ${limit}，运行在完成前结束`,
  dirSummary: (files, size) => `目录，${files} 个文件，${size}`,
  approval: { title: "Approve tool call", keys: { allow: "allow", deny: "deny" } },
} satisfies Messages<typeof en>;
```

`satisfies Messages<typeof en>` 让缺键、多键、参数个数 / 类型不符都在 `tsc` 期报错——两种语言必须同时给。

取用：`const m = msg().print; io.stderr(m.limitTurns(limit))`。用嵌套属性访问，不用字符串键。

## 键名规范

- 领域文件名即一级命名空间（`msg().approval…`）；
- 叶子 camelCase，按「组件.用途」分组：`approval.title`、`approval.keys.allow`、`rewind.skip.failed`；
- 不以文案内容命名（`notInstalled` 可以，`weiAnZhuang` 不行）；
- **整句一个键，禁止片段拼接**：英文语序不同，`"追加写入" + 词 + 路径` 这种要写成一个函数，条件分支写进函数体；
- 插值写成箭头函数，参数类型写在 en 上；复数只英文需要，用 `plural(n, "file")`（不规则词给第三参数）；
- 紧凑时长 `formatDuration(ms)`（`45s` / `2m 10s` / `1h24m`）两种语言共用；`formatTokens` / `formatUsd` / `formatPercent`、日期（ISO）与 compact 状态行记号（`ctx`、`cache`、`$`、`↑ ↓`、`⎇`、`·`）不译；
- 枚举值、命令名、配置键、动作 id、错误码不译。

## 不要这样做

- **模块顶层求值**：`const HELP = msg().cli.help` 会按 import 时的语言定死（SDK / 嵌入场景显示错语言）。改成函数或 getter；`scripts/check-i18n.mjs` 会拦。
- **按文案判断逻辑**：`text === "未安装"`、`reason.startsWith("失败")`。界面文案会随语言变，逻辑用枚举 / 码（第六波 C0 已把三处改掉）。用户**输入**的别名（`批准`、`步骤`、粘贴标记 `[粘贴 #` / `[paste #`）两种语言同时识别，与界面语言无关。
- **模型侧模块 import `src/i18n`**：系统提示、工具（`src/tools/**`）、Plan 提示、内置子 Agent、Skill、压缩、codemode 声明、Memory 工具不得 import——`src/i18n/guard.test.ts` 守着。这些模块需要给人看的错误时抛 `AmaError(code, englishMessage, { detail })`，由界面层按 `detail` 渲染（例：`tools/image-file.ts` → `modes/image-input.ts` 的 `msg().errors.imageFile(detail)`）。
- **宿主解析 `message`**：RPC / ACP 的 `error.message`、`-p` 的 stderr 是人读文本，会随语言变；宿主按 `code` 判断。

## 测试

- 测试缺省钉 zh：`test/helpers/setup.ts` 设 `AMA_LANG=zh` 并 `setLocale("zh")`，子进程也是 zh。迁移批次的验收是现有 zh 帧黄金与断言**字节不变**。
- en 用例自己 `setLocale("en")`（或传 `AMA_LANG=en`），用完在 `afterEach` 里 `setLocale("zh")`；en 帧黄金放 `test/fixtures/tui/en/`。
- `src/cli/lang-independence.test.ts`：同一脚本在 zh / en 下各跑一遍，发给供应商的请求逐字节相同。
- `scripts/check-i18n.mjs`（`pnpm check:i18n`，在 `pnpm ci` 里）：
  1. 棘轮：`src/**` 非测试、非 `src/i18n/` 源码里含汉字的代码行（注释不算）按文件计数，与 `scripts/i18n-baseline.json` 比较，只许降不许升；迁移后 `node scripts/check-i18n.mjs --update` 收紧基线（上调要 `--force` 并在 PR 写明理由）；
  2. `en` 目录里不得有汉字，`zh` 目录里不得留 `TODO`；
  3. 顶层常量不得立即调用 `msg()`。

  收尾批次（W6-I5）把基线清零，改 `--strict`（出现即失败）。

## 体积

bundle 用 `charset: "utf8"` 输出（中文按 UTF-8 原样，不转 `\uXXXX`），抵消英文目录带来的增量。
